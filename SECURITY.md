# Security Policy

## Supported versions

Only the latest version deployed from `main` is supported.

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/jesusgsdev/nhs-pension-calculator/security/advisories/new)
rather than opening a public issue. You can expect an initial response within a few days.

This app runs entirely in the browser and stores no personal data on a server.

## Calculation accuracy

Incorrect pension figures are not security issues; please open a regular
[bug report](https://github.com/jesusgsdev/nhs-pension-calculator/issues/new?template=bug_report.yml) instead.
